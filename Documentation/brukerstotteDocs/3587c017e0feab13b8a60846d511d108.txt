Hvordan logge inn med Buypass ID på smartkort

For å logge inn med Buypass ID på smartkort trenger du følgende:

Smartkort med elektronisk ID fra Buypass
Smartkortleser
PIN-kode til smartkortet

Slik logger du inn:

Gå til den tjenesten du ønsker å logge inn til (f.eks.: www.nav.no, www.altinn.no, www.skatteetaten.no)
Sett inn smartkortet i kortleseren
Velg Buypass ID
Velg Buypass ID på smartkort
Skriv inn PIN-koden til smartkortet
Klikk på "Identifiser"

Om du har glemt eller ønsker å endre PIN-kode på smartkortet, kan du gå til Buypass sine nettsider.

Buypass ID på smartkort gir tilgang til offentlige tjenester på høyeste sikkerhetsnivå (nivå 4).
