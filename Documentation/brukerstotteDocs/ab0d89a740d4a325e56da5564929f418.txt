Hva du kan bruke din elektroniske ID til
Elektronisk ID gir deg tilgang til offentlige tjenester på internett som krever innlogging.

Med nettbaserte tjenester fra stat og kommune kan du for eksempel

beregne pensjonen din på Nav.no
søke stipend på Lånekassen.no
melde flytting på Skatteetaten.no
endre skattekortet ditt på Skatteetaten.no 
lese, rette og levere selvangivelsen din

Offentlige tjenester på internett gir deg trygg tilgang til å kommunisere med offentlige virksomheter. 

E-post

brukerstotte@digdir.no

NB! Ikke send sensitive opplysninger om deg selv og din elektroniske ID på e-post.
