Mottar ikke engangskode på SMS

Om du ikke får engangskode på SMS, prøv å skru av og på mobilen.

Om du fremdeles ikke mottar engangskode på SMS, kan det være feil mobiltelefonnummer som er registrert.

Slik kan du endre mobilnummeret:

Velg Buypass ID
Skriv inn fødselsnummer og passord, klikk på "Fortsett"
Klikk på "Mottar ikke SMS"
Velg BankID og fullfør identifiseringen
Registrer mobilnummer og lagre endringene

Velg Buypass ID og logg inn på nytt.

E-post

brukerstotte@digdir.no

NB! Ikke send sensitive opplysninger om deg selv og din elektroniske ID på e-post.
