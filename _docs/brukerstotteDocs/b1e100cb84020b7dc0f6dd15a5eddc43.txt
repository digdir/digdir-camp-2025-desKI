Hvordan logge inn med Buypass ID i mobil med passord/SMS
Gå til tjenesten du ønsker å logge inn til (f.eks.: www.nav.no, www.altinn.no, www.skatteetaten.no)
Velg Buypass ID i ID-porten
Velg Buypass ID i mobil med passord/SMS
Skriv inn ditt fødselsnummer (11 siffer), og klikk "Fortsett"
Skriv passordet ditt og klikk "Fortsett"
Skriv inn engangskoden du mottar på SMS (6 siffer)
