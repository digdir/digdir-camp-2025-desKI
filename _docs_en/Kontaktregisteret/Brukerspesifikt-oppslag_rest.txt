Introduction
Contact information from the contact and reservation register is most often provided globally through the reference service. However, customers can also receive contact information only related to the logged user, and in some contexts it is more appropriate and use this service.
The use of oauth2
Logged lookups User is based on user -controlled data sharing. In addition to the IDPort scopes OpenID and Profile, one or more of the following scopes must be requested:
| Scope | Description |
|-|-|
| KRR: User/Contact Information.READ | Returns email address and mobile number + time for last update |
|  | Returns the status of whether the contact info can be used for notification in accordance with. The Emergency Regulations §32 |
| | Returns the user's preferred language for communication with the public.  |
| KRR: User/Digitalpost.READ | Returns address for digital mail to citizen |
| | Returns the user's encryption certificate when sending digital mail |
| Krr: User/Spraak.Write | Changes the user's preferred language for communication with the public. |

The following header parameters must be used on Request:
| Parameter | Value |
| --- | --- |
| HTTP method: | Get |
| ACCEPT: | Application/Jose (possibly Application/Json) |
| Authorization: | Bearer \ <Issued Access_token> |
Example of response:
See https://bentrep.difi.no/ lookup service/person for the definition of the Code.

Example of change of language: {#spraak}
The betting below will change the logged in use its preferred language in the contact register of English:
`` `
Patch/Rest/V1/Person
Content-Type: Application/Json
Authorization: Bearer Swdq_PVCT3Hizsiac3zhdummerqffr4ORR508N3P0MTG =
{
 "Spraak": "a"
}
`` `
It is important that customers who use write-api inform the user that changes are happening in a national register and not just for this service.
