There are only three calls you can do with the lookup service; 

retrieve changes 
retrieve persons 
Retrieve print certificate. 

First you need to set up a business certificate and to be used.
Set up client configuration
With certificate from thumbprint:
`` `Charp
Const String Sender Certificate Humb Print = "Fe14593DD66B2 ...";
was configuration = new lookup service configuration (
    Environment. Functional Test Environmental Folishment1,
    Sender Certificate
));
`` `

We recommend loading the Thumbprint certificate because the password is not in the code. Certificate can be installed in for or. See how to install the certificate here.

With certificate from file:
`` `Charp
Const String Sender Certificate Path = @"C: \ Sta \ to \ Certificate \ Certificate.pfx";
was certificate = new x509Certificate2 (
    File.Readallbytes (Sender Certificate Path),
    "Password",
    X509Kystorage flags.exportable
));
was configuration = new lookup service configuration (
    Environment. Functional Test Environmental Folishment1,
    certificate
));
`` `
