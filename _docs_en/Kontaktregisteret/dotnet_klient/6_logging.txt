Generally
The client uses Common.logging API to abstract logging. It is up to the user to imitate API with a suitable log grammar work, but we show how this can be done with Log4net.

Log Request and Response
It is possible to log the full request/response that is sent/received. To activate this, set the following:
{ % highlight charp %}
Lookup service configuration.logk request = true;
{ % Endhighlight %}
It will then be logged to a logger with names.

Note that logging of request and response can provide much poorer performance. There is no need to log this in a production environment.
