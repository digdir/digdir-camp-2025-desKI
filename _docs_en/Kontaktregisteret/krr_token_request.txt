Forcing on the ACCESS-Token for use against the residual reference service
In order to get an access_token to use for authorization against the residual reference service, a JWT Grant must be sent to the machine gate. If your business has gained the right access and layout of both the client and the JWT-Grantet is correct, /token- endpoint in the machine gate will be able to respond to request with an access token. 
We have our own page that describes JWT Grant against the machine gate (JWT Grant.).
