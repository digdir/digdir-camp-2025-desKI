Introduction
The reference service provides public administration access to citizen's registered contact information. The service can be used by public companies and companies that perform services on behalf of the public. 
Kontaktregisterets oppslagstjeneste tilbys gjennom et OAuth2 beskyttet REST-API, sikret med Maskinporten. This makes it easy to implement integrations to the register.
The use of oauth2
Access control of the API uses the machine gate's functionality for machine-to-machine API authorization
Note that the residual interface was previously secured with the "built-in machine gate" in the ID port OIDC, but it is now recommended to use the machine gate.

Available Scopes
API-responsen er avhengig av hvilke scope som er forespurt i tokenet.   Available Scopes are:
| Scope | Description |
|-|-|
| KRR: Global/Contact Information.READ | Returns email address and mobile number + time for last update |
| | Returns the status of whether the contact info can be used for notification in accordance with. Section 32 |
| | Returns the user's preferred language for communication with the public.  |
| KRR: Global/Digitalpost.READ | Returns address for digital mail to citizen |
| | Returns the user's encryption certificate when sending digital mail |
Reservation status will always be returned for the user.
Merk at scopene med -prefix er noe konsolidert i forhold til tidligere.

Note: You will achieve significantly better performance (measured in persons/seconds) by looking up 1000 people once versus 1000 single posts.
header parameters
The following header parameters must be used on Request:
| Parameter | Value |
| --- | --- |
| HTTP method | Post |
| Authorization | Bearer \ <Issued Access_token> |
The Body in Requesten is a JSON structure with an element that will contain a list of up to 1000 personal identifiers.
Example of request
`` `
Post/Rest/V1/Persons
Content-Type: Application/Json
Authorization: Bearer Swdq_PVCT3Hizsiac3zhdummerqffr4ORR508N3P0MTG =
{
 "Personal identifiers": ["20914695016"]
}
`` `
