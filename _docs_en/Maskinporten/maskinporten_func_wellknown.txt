Well-known endpoint
Metadata on machine gate is available on our .Well-Known-End point in accordance with. RFC8414.  
At the end point you will find a link to our JWK endpoint, where the machine sports signing certificate is published.  We strongly recommend customers to use the endpoint of dynamic self-configuration to ensure continuous service delivery when the machine port switches signing certificate.
| Environment | URL | Comment |
|-|-|-|
| Test | https: //test.maskporten.no/.well-known/oauth-Authorization server | (Ver2.makaskerport.no/ is phase out 10.06.2024)
| Prod | https: //maskporten.no/.well-known/oauth-Authorization server |
