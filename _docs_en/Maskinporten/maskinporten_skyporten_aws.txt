Troubleshooting / familiar problems
Here are some familiar problems you can encounter:
Incorrect Token Audience
`` `
AWS STS Assume-Role-WITH-Web-identity--DATURE-SECONDS 900--Role-session-Name $ aws_rolename-session--role-arn ”arn: Aws: IAM: IAM ::
An Error Occurred (Invalididentitytoken) When Calling The Assumerolewithwithwith Suration: Incorrect Token Audience
`` `
This happens because the Audience in the Machine Gate Token does not match the value of the Clientidlist in Open ID Provider Json definition.
