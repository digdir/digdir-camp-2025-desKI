Assign Roles to the Managed Identity
`` `` `Bash
AZ Role Assignment Create - -Role Contributor \
  -Subscription $ SUBSCRIPTION_ID \
  --Assignee-Object-ID $ Service_principal_id \
  --Assignee-Principal-Type ServicePrincipal \
  --scope “$ File_Storage_id”
Federated Identities Also Need "Storage File Data Privileged ..." Roles
AZ Role Assignment CREATE -EASSIGNEE "$ SERVICE_PRINCIPAL_ID" \
  -role "Storage File Data Privilege Contributor" \
  --scope “$ File_Storage_id”
`` `` `` `

The Unpacked Token Will Look Something Like This:

For Azure, Test.Sky.maskerporten.no, Will Respond With A Custom Format Where Subject Includes Scope as A PostFix,

Login with the Federated Credentials and Download a File, two test access
`` `` `Bash
Login With Skyporten Token
AZ Login - -Service -Principal -u $ Identity_Client_id -t $ Azure_Tenant_id - -Federated token $ machine gate_token
List files
AZ Storage File List--ACCount-Name $ Storage_acc--Share-Name $ Storage_Share | jq. [0] .name
Download a File
AZ Storage File Download--ACCount-Name $ Storage_acc--Share-Name $ Storage_Share--Auth-Mode Login--ENABLE-FILE-BACKUP-REQUES

Troubleshoot
Missing Trailing Slash () In Issue Argument When Calling 

The Issuer Must Exactly Match the Issuer in the Credential. UPDATE OR RECREATE THE CREDENTIAL WITH TRAILING SLASH IN THE ISSUS.
Token Timeout Error (as Expected Since Token has timed out)

Wrongly Using Service Principal ID Instead of Client ID

Use Identity_Client_id Instead.
