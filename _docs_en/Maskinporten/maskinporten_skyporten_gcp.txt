At GCP, it is WORKLOAD Identity Federation used for its Skyporten OAuth2/OIDC integration.
Now follows a recipe for how it can be done via Gcloud. Contact us if you want help getting started.
Log into Gcloud
Here you need to log in with the cloud user your organization has given you. It should have wide enough privileges (roles, policies)
to be able to perform the tasks below.

Put Google Project
This is the name of the GCP project you want to set up the SkiPort access in.

Create a new WORKLoad Identity Pool
It is this that is used to access the machine port using Oidc.
`` `
You may want to replace the name Skyportpoc
Export Workload_pool_ID = Skyportenpoc
GCLOUD IAM WORKLOAD-IDENTITY-POOLS CREATE "$ WORKLOAD_POOL_ID" \
    -Location = "Global" \
    ---description = "Pool for the Skype POC" \
    --Display-Name = “Skyportenpoc try”
`` `
Define Oidc Identity Pool Provider
Note that we specify here. A specified Audience is required
By GCP and thus we recommend choosing a cloud of prefix for your own domain. This does not need to be a functioning
Domain.
This forces consumers to specify that the machine-gate token should have. This is specified
in when the consumer builds up his JWT-Grant.
`` `
Export Required_Audience = "https: // Skype."
Export Provider_ID = SkiPort provider
GCLOUD IAM WORKLOAD-IDENTITY-POOLS PROVIDERS CREATE-OIDC $ Provider_ID \
    -Location = "Global" \
    --WORKLOAD-IDENTITY-POOL = $ WORKLOAD_POOL_ID \
    --attribute mapping = "attribute.maskepartenscope" = "assertion.scope", "Google.subject" = "assertion.consumer.id", "attribute.clientaccess" = "\" Client :: ::::
    --sisuer-Uri = "https://test.sky.maskanporten.no" \
    -allowed Audiences = $ Required_Audience \
    -Description = "Oidc Identity Pool Provider for the Machine Gate"
`` `

Troubleshoot
Invalid Jwt Claim
This may be due to final slash in.
When the JWT token is generated with the audience, it must be done without any final slash (trailing slash).
If the query against the machine gate has trailing slash in the token for the value, you will get the error:

The solution is thus to remove the final slash in the audience when generating the JWT token.
