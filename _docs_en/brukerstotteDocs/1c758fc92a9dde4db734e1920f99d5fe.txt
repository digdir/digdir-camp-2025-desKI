iOS - iPhone/iPad (Safari and Chrome)

Here you will find instructions for deleting cookies in different iOS browsers:

Safari
Go to "Settings"
Select "Safari"
Select "Empty Log and Site Data"
Click "Empty Log and Data"
Close Settings 
Open the Safari app and try logging in again
Safari (iOS 17.1)
Go to "Settings"
Select "Safari"
Select "Empty Log and Site Data"
Make sure the time is set to the "entire log"
Tap Delete Log
Chrome
Start the browser "Chrome"
Tap Menu- three horizontal dots down in the right corner of the iPhone/in the top right corner of the iPad
Select "Log"
Select "Delete browser data" 
Check that "time period" is set to "all dates"
Check that "cookies and site data" are squatted by
Click "Delete browser data"
Close browser and open again before trying to log in again
