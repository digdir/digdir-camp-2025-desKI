Android- mobile and tablet (built-in, Firefox and Chrome)

Here you will find instructions for deleting cookies in various android browsers:

Mobile phone:

Android Mobile - Built -in browser

Start the browser "Internet"
Click Menu - three horizontal lines down in the right corner
Select "Settings"
Select "Personal Browser Data"
Select "Delete Network Data"
Check that "inf. Cap. And side data" is squatted by
Click "Delete"
Close browser and open again before trying to log in again


Android Mobile - Firefox

Start your browser "Firefox"
Click Menu - three dots down in the right corner
Select "Settings"
Select "Delete browser data"
Make sure "info capsules" are squatted by
Click "Delete browser data"
Click "Delete"
Close browser and open again before trying to log in again

Android Mobile - Chrome

Start the browser "Chrome"
Click Menu - three horizontal dots in the top right corner
Select "Settings"
Select "Privacy and Security"
Select "Delete browser data"
Make sure "cookies and data from websites" are squatted by
Click "Delete Data"
Click "Empty"
Close browser and open again before trying to log in again.

Android tablet - Firefox
