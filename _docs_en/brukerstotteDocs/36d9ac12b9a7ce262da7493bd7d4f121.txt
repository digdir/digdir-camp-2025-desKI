"Warning: Your user is closed"

"Warning: Your user is closed so you can no longer log in with the ID port. This normally only happens on the request of the individual. If you believe this has happened with an error or you would like to reopen your user, contact the Norwegian Digitalisation Agency."

If you get this error message, please contact the ID port support at (+47) 800 30 300
