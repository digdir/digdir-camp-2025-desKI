Minid
MinID provides access to public services at a significant level of security (level 3).

MinID is a two-factor solution, which means that you have to use two factors to log in to a service. One factor is a self -selected password. The second factor can choose the user himself, and is a one -time code you receive by SMS or a push notification in the MinID app.
