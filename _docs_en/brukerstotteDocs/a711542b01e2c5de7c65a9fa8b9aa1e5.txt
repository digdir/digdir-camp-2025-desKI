Access to personal data (GDPR)

Everyone who uses the Norwegian Digitalisation Agency's common solutions has the right to request access to personal data stored in these common solutions.

When applying for access, you must choose which service you want access to. Below you will find information about these solutions.

Access requirements must be sent to the Norwegian Digitalisation Agency. Use the form here.

The ID port
The ID port is a safe login solution for public services on the Internet.

The contact and reservation register
The contact and reservation register is a joint solution that all public companies should use in contact with the inhabitants. The businesses can use the register to send out notice and service messages by SMS or e-mail. The companies can also find information about the citizen being reserved for digital communication with the state and municipality.

donkey
Esignment is a service that provides opportunities for citizens to sign letters electronically from public companies with Eid.
