How to log in with BankID with code chip

To log in with BankID you need:

Birth number
Code generator (eg code chip or code app) from your bank
Password

Go to the service you want to log in to (eg at: www.nav.no, www.altinn.no, www.skatteaten.no)

Select BankID in the ID port
Enter Birth Number, 11 digits
Select the login "BankID with code chip"
Enter one -time code from code chip
Enter personal password

Note that BankID must be activated at your bank to use it in the ID port. You can enable BankID for public services by logging into your online bank, selecting BankID in the menu and then ordering or activating BankID. If you need help creating or activating BankID, contact your bank.

BankID provides access to public services at the highest security level (level 4).
