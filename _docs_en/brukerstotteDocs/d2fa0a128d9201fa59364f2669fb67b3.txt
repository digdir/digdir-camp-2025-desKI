The ID port
The ID port is a common login solution for public services on the Internet. The ID port provides access to over 1000 services from the state and municipality. The ID port is operated by the Norwegian Digitalisation Agency.

To log into services from the state and municipality on the Internet, you must have an electronic ID (e-ID). An electronic ID is important to confirm that you are the one you are pretending to be.

In the ID port you can choose between different options for electronic ID:

Bankid
