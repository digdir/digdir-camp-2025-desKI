Introduction
Evisation is a search service for anyone looking for information related to the public sector. Meetings are a part
of the content that can be applied for.

The use of e -insight is compulsory for the state -owned enterprises covered by the regulations of section 6 of the Public Act.
Digitization Circular (external link)
The use of e -insight is recommended for state enterprises that are not covered by the regulations of section 6 of the Public Act.
Digitization Circular (external link)

Emypesing is used to publish information to e -insight. Usually, e-dissemination is used through the e-insight client, but
This is a temporary solution for the suppliers to a greater extent support integration directly through eForsing.

Publishing of meetings is represented with the following process for the recipient:
| Process name | Process identifier |
| ----------------- | --------------------------------------------------- |
| Journal mail | URN: NO: DIFI: Profile: Evisation: Journal post: Ver1.0 |
Publishing of meetings is represented with the following process for sender:
| Process name | Process identifier |
| ----------------- | ------------------------------------------------- |
| E-Insight response | URN: NO: DIFI: Profile: Evisation: Response: Ver1.0 |
A business always acts as a sender, while the recipient of meetings is always an insight at Digdir.
Message content
There is only one document type supported to publish meetings for e -insight and this is only supported by e -insight
messaging service.
| Document Type | Message Services |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Publishing | E -Insight messaging |
e-insight-receipt
Address messages
Messages are addressed from the sender's organization number to Gigdir's organization number.
Because the process is supported by a single document type supported by a single messaging service there is none
Business rules related to choosing these.
Send messages
Before a business sends a message a voluntary capability lookup to see if the recipient supports
The meeting process. In that case, document type and messaging service are provided. The business then builds the message before it is sent
to the integration point. The integration point Routes the message to Evisyn's messaging service.

Notification
Sender System receives status messages when a message is delivered. Sender's system also receives status messages at
error situations and when a message is not delivered within the defined life. Sender's system can notify
The sender of both successful broadcasts and deviations.
