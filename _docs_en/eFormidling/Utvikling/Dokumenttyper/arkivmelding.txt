The archive message
The archive message contains archive-specific metadata and is designed for communication between the case and archive system.
The archive message follows the standard.
The standard must not be confused with the business report.
The use of the standard archive message is described on archive reports.
One or more documents
The archive message contains document references with file names for one or more documents. Each of these referenced
The documents must be included. The types of documents supported depend on the recipient and are not known in advance. This
means that attempts to send documents that are not supported by the recipient fail at reception.
All file format is initially supported, but in practice the recipient's system will in many cases make stricter requirements.
Therefore, PDF is recommended. Known restrictions:

Recipients using Altinn Digital Post support HTML and attachments with arbitrary file format
Recipients using KS Svarut and Replyer basically support only pdf but can be configured to support more 
file format at the expense of delivery guarantee

Enriching and transformation
In order to support recipients using messaging services than e -officing messaging service, the integration point must
Enrich and transform outbound messages:

Transformation from archive message to Altinn Digital Post
Transformation from archive message to KS Svarut

To support reception from senders using messaging services other than e -officing messaging service must
The integration point enrich and transform incoming messages:

Transformation from KS Replyer to archive message

When using the Integration Point's interface, the integration point transfers outbound messages to
Archive message. If the recipient uses KS Svarut or Altinn Digital Post also transforms the archive message to it
Current messaging service:

Transformation from Best/Edu to archive message

By using the Integration Point's interface, the integration point transforms incoming messages directly
To Best/Edu:

Transformation from archive message to Best/Edu
Transformation from KS Replyer to Best/Edu

Differences in the data structures in Best/Edu, the archive message, KS Svarut and Altinn Digital Post in some cases entail that
Not all metadata from the sender can be delivered to the recipient.
