The document type consists of a standard Business Document (SBD).
The document type has the identifier.
The document type is sent in response to an archive message.
The document type is always sent with the process, regardless of which
process the original archive message had.

Enriching and transformation
When one sends an archive message, one should expect an archive message receipt back. Since similar concept does not exist
In Altinn Digital Post or KS Svarut, the integration point produces archive notification receipt in these cases. This
Allows the sender system to have consistent behavior regardless of which messaging recipient is reached.
When one receives an archive message, one should send an archive message receipt back. Since similar concept does not exist in
KS Svarut will not be communicated to the recipient in this case. This makes that
The receiving system may have consistent behavior regardless of which messaging sender used.
When using the Integration Point's interface, the integration point transforms outgoing Best/Edu AppreceiT
for archive message receipt. 
By using the interface of the integration point, the integration point transforms incoming
Archive Message receipt for Best/Edu AppreceiTT.
