This page shows an example of the agreed message exchange. The recipient of the example is the Directorate for Management and
Financial management (DFØ) with organization number. Sender and recipient have agreed in between that they should use
agreed message exchange to communicate. They have also agreed to give the agreed message type identifier
. Sender must build and send messages with content as agreed for this type of message. Recipient
must recognize this agreed message type and interpret and process incoming messages of this type as agreed
between sender and recipient.
