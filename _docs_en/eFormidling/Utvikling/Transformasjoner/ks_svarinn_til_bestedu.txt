Messages. The integration point supplements incoming messages with information from configuration, standard values and
Lookup with third parties. Note that incoming messages from KS Replyer are treated differently depending on whether
The integration point is configured with the interface Best/Edu or not. The table below shows how incoming
Messages from KS Replyer are processed if the integration point is configured with the interface Best/Edu.
