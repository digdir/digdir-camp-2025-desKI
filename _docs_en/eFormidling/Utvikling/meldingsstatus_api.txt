This page describes the message status API and patterns of use for this.
Em shape uses message statuses to support troubleshooting, errors and statistics. This has previously
been delivered along with log but to ensure reliable handover of message statuses is now established an API
to receive these.
The integration point uses the message status service under the hood. There is usually no need to integrate directly
against the message status service but in some rare cases a business wants to communicate with businesses at
Emorting without even running an integration point.
