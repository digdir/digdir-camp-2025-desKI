This page describes the address service's (Service Registry) API and patterns of use for this.

API documentation (external link)

The address service is a key component offered by e -mouring.
The integration point uses the address service under the hood, and the capability reports the integration point offers bases
themselves on information from the address service. It is usually not necessary to integrate directly to the address service but in
Some rare cases want a business to communicate with businesses on eFonsemidling without even running a
Integration point.
The address service is a facade against the address services for the various messaging services supported by eFo -mediation. IN
additions are business rules for what are the recipients' preferred channels in different contexts implemented in
The address service.
The address service also provides access to the certificate catalog (operated) in e -molding.

Service Registry API uses OAuth2 for authorization and expects self -sufficient JWT from the machine gate. JWT requests to
The machine gate is expected to contain the X5C for the Norwegian Business Certificate (Seidv1 or Seidv2) JWT request
was signed with.
