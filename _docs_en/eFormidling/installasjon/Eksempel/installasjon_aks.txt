5. Azure Key Vault and Azure Key Vault Env Injector
Azure Key Vault can be used to save Secrets. Here we will save the password of the keystor the integration point uses.
The step assumes that Azure Key Vault is set up in the Azure Portal. Alternatively, it can be created via the following command:

Add Secret for Keystore passwords

To make this Secret as an environmental variable so that it can be supplemented to the integration point, uses
We akv2k8s (Azure Key Vault to Kubernetes) (https://akv2k8s.io/)

AKV2K8S needs reading access to Azure Key Vault to retrieve Secrets, either via Service Principal or Managed Identity. The cluster in this example was set up with Managed Identity:

Alternatively with Service Principal:

Turn on Env-Injection for Default Namespace

Key Vault Secret's must then be made available to the cluster:

7. The integration point
The following deployment can be used as an example of setting up the integration point with DPO in the staging environment. Note that properties
Set as environmental variables and must be replaced with own values.
`` `yaml
APPERSION: APPS/V1
Kind: Deployment
Metadata:
  Creationtim Stamp: Zero
  Labels:
    App: IP staging
  NAME: IP staging
Spec:
  Replicas: 1
  Selector:
    Matchlabels:
      App: IP staging
  Strategy: {}
  Auditory HistoryLimite: 3
  Template:
    Metadata:
      Creationtim Stamp: Zero
      Labels:
        App: IP staging
    Spec:
      Containers:
      - Image: Digdir/Integration Point: 2.24.1
        NAME: Integration point
        Resources: 
          Limits:
            Memory: 3072mi
          Requests:
            Memory: 2048mi
        Volume Mounts:
        - Name: Keystore
          Mountpath: "/Etc/Keystore"
          Readonly: True
        Env:
        - Name: Spring_profiles_Active
          Value: "Staging"
        - Name: Difi_move_org_number
          Value: "123123123"
        - Name: Difi_move_org_Kystore_alias
          Value: "123123123"
        - NAME: DIFI_MOVE_ORG_KYSTORE_PATH
          Value: "File: /etc/keystore/keystore.jks"
        - NAME: DIFI_MOVE_ORG_KYSTORE_PASSWORD
          Value: "KV-kspass@azurekeyvault"
        - NAME: DIFI_MOVE_FEATURE_ENABLEDPO
          Value: "True"
        - NAME: DIFI_MOVE_FEATURE_ENABLEDPE
          Value: "False"
        - NAME: DIFI_MOVE_DPO_USERNAME
          Value: "Username"
        - Name: Difi_move_dpo_Password
          Value: "Password"
        - Name: Difi_move_nextmove_usedbpersistence
          Value: "True"
        - Name: Spring_datasource_url
          Value: "JDBC: Postgresql: //postgresql.default.svc.cluster.local: 5432/Postgres"
        - NAME: SPRING_DATASOURCE_USERNAME
          Value: "Postgres"
        - Name: Spring_datasource_Password

            Secretkeyrf:
              NAME: POSTGRESQL
              Key: PostGresql-Password
