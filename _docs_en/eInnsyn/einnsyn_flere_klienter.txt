When using multiple integration points or e-insight clients on the same server, you must use different gates. If you are going to use one integration point and several e-insight clients, you must change the ID, name and port of the EVAR's client service. In addition, each e-insight client must have its own inputdirectory folder.

You must also point to go towards the correct integration point and gate. The gate that the integration point and the e-insight client use need not be the same.
