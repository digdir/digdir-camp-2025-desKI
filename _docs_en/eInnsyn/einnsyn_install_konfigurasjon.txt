Transportation
One can also turn on support for transport protection integration point. See how here.
In the client one must then change to -dapplication.moveurl = https: //servername.no: port number.
Loggot
In addition, you can enter logging if desired. This allows you to rotate logs in size and choose how many you want to take care of. The standard size here is 10MB, you can change to the desired size. The number of files taken care of is 8. This can also be changed. Make sure this is within the tag like the rest of the configuration.
