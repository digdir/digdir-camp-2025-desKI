After you finish editing the e-insight-client.xml file, you must install the service. To do this, you need to open a command window as an administrator. Then navigate to the e-insight folder (eg) and run the following commands. 

e-insight-client.exe install
e-insight-client.exe start

These commands must be run without any form of slash or hyphen front. Written exactly as in the picture below:

You can check the status of the service by using the following command in the same command window:

e-insight-client.exe status

Verify that the e-insight-client service has started
Message no.difi.evisyn.Application - Started Application in 7.121 Seconds (JVM Running for 7,951) should be in the e -insight -client.Out log. This indicates that the service has starts and listens to the Inputdirectory folder.
