To upgrade to a new version of the Esssyn client, you must change the version number in the e-insight-client.xml Fila. Specifically, this line. When making changes to this XML file, you need to reinstall service.  Whether it is a new version or anything else that is changed. 
After you finish editing the e-insight-client.xml file, you must reinstall the service. To do this, you need to open a command window as an administrator. Then navigate to the e-insight folder (eg) and run the following commands. 

e-insight-client.exe stop
e-insight-client.exe uninstall
e-insight-client.exe install
e-insight-client.exe start
