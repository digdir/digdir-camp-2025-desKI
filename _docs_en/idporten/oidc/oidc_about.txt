About the pages
These pages are the documentation of the ID port's OpenID Connect Provider.  The documentation is openly accessible and maintained on the github repoe https://github.com/difi/idporten-portc documentation. Issues and Pull Requests are welcome!
Technical

The pages are published by github pages at https://difi.github.io/idporten-oidc documentation/
The pages are written in Markdown and use a theme/layout based on Jekyll Documentation Theme by Tom Johnson.
Graphs and sequence diagrams are generated directly in user browser, based on Mermaid.
Atom with Markdown Preview Enhanced plugin is recommended for writing.
