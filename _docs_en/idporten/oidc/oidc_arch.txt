Authentication services in the ID port
The ID port offers authentication of end users up to web services.  
The customer can choose the OIDC protocol when connecting to the ID port.  All services participate in a common Circle-of Trust with Single Signon (SSO) among themselves.
Securing APIs
The OIDC interface to the ID port The OpenID Connect Provider can also issue API access authorizations at 3rd.

The API access can be login-based (implicit consent), user-controlled (explicit consent), or machine-to-machine-based. In the first two cases, the authorization applies only to a single citizen, while the latter case is intended for home -based authorizations.
