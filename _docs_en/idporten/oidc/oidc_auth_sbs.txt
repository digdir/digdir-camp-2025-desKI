Overall description of the application
By thick clients we mean applications that are installed and run locally on a computer. Examples of this are Microsoft .net WPF or Winforms.
In the OAuth2 context, this is a native client, since it cannot protect a client secret/business certificate, and is treated in the same way as login to mobile apps.
Thick clients should:
* Recorded with 
* Recorded with joint client_id for all bodies
* Authentication should take place in external browser
* Use Loopback Interface Redirection (see below)
Loopback Interface Redirection

Structure on the token
The ID token is identical as using the authorization code flow.  Although it is the access_tokenet to be used further, the customer must first validate the id_token in accordance with the usual best practice for Oidc.
The access_token will contain the birth number of the inhabitant, the scoped registered, and the outlet time of the token.
