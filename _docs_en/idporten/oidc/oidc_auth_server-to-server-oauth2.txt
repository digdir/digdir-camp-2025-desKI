Introduction
The ID port no longer offers support for the "Machine Gate-ID port".
In the introduction of the ID-port's OIDC boundary in 2017, the machine gate was a feature of the ID port.  Later, in 2019, the machine gate was established as a separate OAuth2 Issu.
Customers who are still using JWT-Grants against the old ID port must switch to using the machine gate.
