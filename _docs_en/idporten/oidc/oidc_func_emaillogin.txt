Can I have Norwegian birth or D number?
No, the ID port will not try to find Norwegian birth or D number on email login users. Email login users are self-registered users who do not necessarily have any connection to the National Register.
How to enable email login login?
A service activates the email login button in the ID port's login window by including the value or in the attribute in the login request.  
If only the email login value is stated in the ACR, the ID port will jump directly to email login. In this way, the service can create its own login button for email login users if this should be desirable.
As of today, email login is not enabled by default, so this must be activated per service.
