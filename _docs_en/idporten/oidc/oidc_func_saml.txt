Saml in the ID port
The ID gate began as a pure SAML service in 2010. The OIDC interface was introduced in 2017 and quickly became very popular. The ID port only supports OIDC, but we temporarily offer a simplified SAML interface for customers who cannot use the OIDC interface. The Saml interface is closed down on 01.01.2026

The Saml interface is closed down on 01.01.2026

Collar architecture
The ID port's SAML support is based on a SAML proxy that translates the customer's SAML messages to the OIDC against the ID port, and Vice Versa.

Customer's metadata (SP)
Updating customer metadata is a manuel process at Digdir. Metadata must be sent to servicedesk@dir.no for change. We need metadata with the following content:

entityid
assertionconsumerurl
logout-url
Public key of the business certificate (same certificate for both signing and encryption)

Restrictions in saml-proxy
SAML-PROXY is not a full-fledged IAM product, but simple proxy in front of the OIDC solution. Among other things, the SAML proxy has the following restrictions:

Only supports artifactresolution (not http-mail binding)
Contact info from the contact and reservation register cannot be handed out in Assertion
