RAR support (in design)
Rich Autorization Requests (RAR) is an upcoming OAuth specification that makes it possible to request transaction-based consents or more complicated authorizations in a standardized manner. Initially, we intend to use this to build the so-called "employee gate", but there is also an identified need to be able to use this to offer the disagreement/proxy-based login.
