This "release" contains larger projects and potential pilots that would like to implement in 2020.

New functionality:
Procurement New Eid Agreements-The ID port and Esignering (Shipped)
Today's agreements with the Eid suppliers run until November 2020, and new agreements must be made. The new agreements will be based on requirements that follow from the new regulations for trust services (introduced November 2019).
Notify Norske Eid to Eidas (in Design)
Conduct a peer review of Norwegian Eid solutions to the EU, so that Norwegian citizens can use their eider on European services.
Piloting of Employee Gate (IN DESIGN)
We would like to pilot the "Employee Gate" in 2021. The pilot will contain at least:

Combine login with a "spectator voter" from e.g. Altinn Authorization or other sources of employee relationship

Possibly we can see if we can test out:


self-service Circle-of-Trust 


Use of Azure AD


P.T. It is planned to begin development in March/April, with the goal of sharp pilot just before the summer.
New system architecture for the ID port (in Development)
The transition from SAML integrations to OIDC integration is fast. As a result, Difi decided in a project in 2019 that ID porte's system architecture must be changed to the OpenID Connect / OAUTH2 section becoming the core of new architecture. One must look at whether it is possible to use a shelf product IAM product instead of today's proprietary solution.
Rewriting into a new system architecture begins now, and will continuously until the current operating agreement expires in late 2021.
By 2021, we envision doing the following:


Development of the first version of "New ID port". 


Trial operation of the new ID port in the form of pilot on the employee gate.


Trial operation in production in Public Cloud (Azure)
