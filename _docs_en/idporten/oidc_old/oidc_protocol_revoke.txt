About
The Endpoint is thoroughly documented in rfc7009
When the Client Calls the Revoke Endpoint With Valid Token (Einher an access_token or a refresh token), that token and all other tokens Associated with the underlying grant - for that specific client only Only - are invalidated in the ID gate.
Note that the SSO-session Itself is not affected by a Revoke, and any tokens Issued to other clients during the same SSO-session are still valid.
